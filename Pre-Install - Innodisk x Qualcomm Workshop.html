安裝教學：VS Code + Claude CodeInstall walkthrough: VS Code + Claude Code

跟著下面步驟裝到能用即可，不含怎麼執行 Agent Skill（現場另外教）。畫面以 Windows 為準。 Just follow the steps below to get everything installed and ready — actually running the Agent Skill is covered separately, on-site. Screens assume Windows.

第一部分・安裝 VS CodePart 1 · Install VS Code

  1. 點連結前往官網：code.visualstudio.com，點「Download for Windows」下載。 Click here: code.visualstudio.com, then click "Download for Windows".
  2. 到「下載」資料夾雙擊安裝檔開啟。少數電腦會跳出 安全提示。 Double-click the installer in your Downloads folder. A few PCs show a security prompt here.
  3. 選「我同意」授權合約，按「下一步」。 Select "I accept the agreement", then click Next.
  4. 其餘用預設，一路按「下一步」，確認「加入 PATH 中」有打勾，按「下一步」→「安裝」。 Keep the defaults, click Next through the wizard, make sure "Add to PATH" is checked, then click Next → Install.
  5. 安裝完成後按「完成」，VS Code 會自動開啟。 Click Finish when it's done — VS Code opens automatically.

第二部分・安裝並登入 Claude CodePart 2 · Install and sign in to Claude Code

  1. 點左側 Extensions 圖示（四方塊，或按 Ctrl+Shift+X），搜尋 Claude Code。 Click the Extensions icon (four squares, or press Ctrl+Shift+X) and search for Claude Code.
  2. 找到發布者 Anthropic 的那個（Claude Code for VS Code），點「Install」，等待安裝完成。 Find the one published by Anthropic (Claude Code for VS Code), click "Install", and wait for it to finish.
  3. 安裝完成後，點右上角新出現的 Claude Code 圖示（橘色圖案），會打開登入畫面，點「Claude.ai Subscription」。 Once installed, click the new Claude Code icon (orange) in the top-right corner — a login screen opens; click "Claude.ai Subscription".
  4. VS Code 會問是否開啟瀏覽器，點「Open」。 VS Code asks whether to open the external website — click "Open".
  5. 用訂閱 Claude.ai 帳號（Pro／Max）登入（Google／Apple／Email 都可以）。 Log in with a Claude.ai account on a subscription plan (Pro / Max) — Google, Apple, or email all work.
  6. 瀏覽器會問是否授權 Claude Code 連接你的帳號，點「Authorize」。 The browser asks to authorize Claude Code to connect to your account — click "Authorize".
  7. 回到 VS Code，面板會變成可以打字對話的聊天框，代表裝好登入成功了。（沒反應就重開 VS Code。） Back in VS Code, the panel becomes a chat box you can type into — that means it's installed and signed in. (If nothing changes, restart VS Code.)

不想裝也沒關係，現場提供手動腳本一樣能完成。 Don't want to install this? A manual script will be available on-site too.

02

QUD (Qualcomm USB Driver)

Qualcomm USB 驅動Qualcomm USB driver

  1. 打開 Qualcomm Software Center。Open Qualcomm Software Center.
  2. 在 Tools 搜尋 Qualcomm USB Driver，下載並安裝。Under Tools, search Qualcomm USB Driver, then download and install.

小提醒：一次只能安裝一個工具，若畫面顯示 No logs found，代表該工具尚未安裝。 Note: please install only one tool at a time. If a No logs found message appears, it means the tool hasn't been installed yet.

03

WSL + Ubuntu Setup

安裝環境是當日實作（hands-on）的基礎，請務必於課前完成配置。 A pre-configured environment is essential for the hands-on session; please make sure the install succeeds beforehand.

  1. 以管理員權限開啟 Windows PowerShell，執行以下指令。 Open Windows PowerShell with Administrator rights and run the following command.
    PowerShell
    wsl.exe --install -d Ubuntu-22.04 --no-launch
  2. 執行以下指令，檢查是否安裝成功。 Run the following command to check the install succeeded.
    PowerShell
    wsl.exe --list --verbose

PowerShell 顯示 Ubuntu-22.04 就代表成功了！ As long as PowerShell shows Ubuntu-22.04, you're good to go!

若安裝過程中遇到權限限制，請聯繫貴公司的 IT / MIS 部門協助排除。 If you hit a permissions restriction during install, please contact your company's IT / MIS department for help.

wsl.exe --list --verbose 沒看到 Ubuntu-22.04，或安裝過程中出現錯誤？點開查看解法Don't see Ubuntu-22.04 in wsl.exe --list --verbose, or hit an error during install? Click to see the fix

請依序執行以下指令：Run the following commands in order:

  1. 查看可安裝的發行版清單。List the available distros online.
    PowerShell
    wsl --list --online
  2. 更新 WSL 核心元件。Update the WSL core components.
    PowerShell
    wsl --update
  3. 改用網頁下載方式重新安裝 Ubuntu-22.04。Reinstall Ubuntu-22.04 using web download instead.
    PowerShell
    wsl --install -d Ubuntu-22.04 --web-download --no-launch
