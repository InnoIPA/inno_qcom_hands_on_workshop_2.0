下載前必讀Before You Download

1
下載三個檔案，放在同一個資料夾Download all three files into one folder 務必一個一個下載，三個檔案放在同一個資料夾（不要放進子資料夾）：hands_on_workshop_package_v2.0.0.zip（4.10 GB）、workshop_exmp-q911_v2.3.5-7-gfc417e2_image.zip（2.34 GB）、setup_workshop.bat（10 KB）。Download them one at a time, all into the same folder (not inside a subfolder): hands_on_workshop_package_v2.0.0.zip (4.10 GB), workshop_exmp-q911_v2.3.5-7-gfc417e2_image.zip (2.34 GB) and setup_workshop.bat (10 KB).

不能改名字——腳本是照名稱去找的，改了名字就會找不到、直接失敗。Don't rename them — the script locates them by name, and renaming breaks that.

2
雙擊 setup_workshop.batDouble-click setup_workshop.bat 雙擊後會自動把兩個檔案搬到 C:\iq_workshop\ 底下並解壓縮。跑完看到兩行都是 OK: 開頭就代表成功。It moves both files into C:\iq_workshop\ and extracts them. If it finishes with both lines starting with OK:, it worked.
完成後應如下Expected result
C:\iq_workshop\   ← 務必要在這個路徑!!!← must be at this exact path!!!
├── hands_on_workshop_package_v2.0.0   ← 要解壓縮!!← must be extracted!!
└── workshop_exmp-q911_v2.3.5-7-gfc417e2_image   ← 要解壓縮!!← must be extracted!!
也可以不用腳本，手動處理：自己建立 C:\iq_workshop 資料夾，把兩包從下載的位置搬進去，再解壓縮。You can also skip the script and do it by hand: create a C:\iq_workshop folder yourself, move both packages into it from where you downloaded them, then extract the image.

解壓縮後檔案不要四散——不要讓裡面的檔案跑到資料夾外面，解壓完應該還是一個完整的資料夾。Don't let the extracted files scatter — don't let them spill outside the folder; the result should still be one intact folder.

3
執行環境檢查Run the environment check 雙擊執行或用指令執行皆可：C:\iq_workshop\hands_on_workshop_package_v2.0.0\scripts\preinstall-check.batDouble-click it, or run it from the command line: C:\iq_workshop\hands_on_workshop_package_v2.0.0\scripts\preinstall-check.bat
4
全部出現綠色 PASS 才開始工作坊Only start the workshop once everything shows a green PASS
